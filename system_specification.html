1 システム概要 & 目的

目的: エンジニア向けに最適化されたITニュース・技術トレンド収集プラットフォームを提供する。多言語ソース（日本・グローバル）からの情報集約、AIによる要約、およびユーザーごとの効率的な情報管理（ブックマーク・既読管理・個人メモ）を単一のWebインターフェース上で実現する。

対象ユーザー: ITエンジニア、開発者、テックリード、インフラエンジニアなど、最新技術動向を迅速にキャッチアップしたい個人プロフェッショナル。

2 画面レイアウト・UI設計

本システムはモダンな3カラムダッシュボードUI（デスクトップ最適化 / レスポンシブ対応）を採用しています。

左サイドバー

ロゴ、ダークモード、日本/グローバル切替タブ、カテゴリ一覧、ビューフィルタ（すべて・ブックマーク・既読・トレンド）。

中央メインコンテンツ

インクリメンタル検索バー、期間フィルタ、フィード更新、サムネイル付き記事一覧カード。

右スライドパネル

記事詳細、言語切替（日本語/原文）、AIローカル要約、マイメモ入力欄（自動保存）、関連記事リンク。

3 主要機能仕様

  • リージョン管理: 国内テックブログとグローバルメディア（Hacker News等）のスコープ切り替え。
  • 検索・フィルタリング: キーワード（タイトル・ソース・タグ）および期間（24時間以内/7日以内/全期間）による絞り込み。
  • パーソナライズ管理: 詳細パネル表示に伴う自動既読化、ワンクリックのブックマーク登録、ユーザー独自の「マイメモ」自動保存機能。
  • AI要約 & 多言語対応: 長文記事の重要ポイント箇条書き要約、および日本語翻訳と原文の切り替え表示。
  • ITトレンド可視化: Chart.jsを用いた主要技術スタック（AI/LLM、React、Kube等）のトレンド指数推移グラフ（モーダル表示）。

5 技術スタック & 非機能要件

技術スタック

  • Markup: HTML5 / Tailwind CSS (v3)
  • Icons: Lucide Icons
  • Chart: Chart.js
  • Script: Vanilla JavaScript (SPA設計)

非機能要件

  • ダークモード対応（Class toggle）
  • スムーズなスライドパネルアニメーション
  • ローカルステートによる高速な応答性
